Credential security

PrimePay deliberately does not provide a way to retrieve an API secret after issuance. That is inconvenient in precisely the way security should be.

Store the secret securely Save the secret in your server-side environment or a proper secrets manager. Never expose it in browser JavaScript or commit it to source control.
✓
Secrets are shown once Creation and rotation responses are the only places the secret is returned.
✓
Rotation invalidates the old secret Use rotation when a credential needs to be replaced.
✓
Revocation blocks access Revoked credentials cannot authenticate developer API requests.
