Settlement Operations

Monitor settlement-related transaction data, currencies, exchange-rate metadata and reconciliation state without pretending PrimePay already has a settlement batch engine that it does not.

V1 settlement boundary PrimePay V1 exposes settlement currency, exchange-rate and reconciliation information on payment and transaction records. It does not currently expose dedicated settlement batches, settlement schedules, bank payout instructions, settlement exports or an administrator settlement-release endpoint. This page therefore reports actual settlement metadata rather than manufacturing settlement events.
