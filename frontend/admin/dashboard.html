PrimePay V1 dashboard principle

This dashboard intentionally distinguishes between implemented backend capabilities and frontend surfaces that are awaiting their corresponding APIs. No revenue, merchant counts, transaction totals, settlement figures or system metrics are fabricated here. When the backend gains those endpoints, this dashboard can consume the real data without rebuilding the interface.
