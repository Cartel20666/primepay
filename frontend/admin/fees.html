Fee Administration

A financial control workspace for understanding how PrimePay fees, provider costs, total transaction fees and merchant net amounts are represented in the current ledger architecture. The page reports actual transaction data where available and does not invent a fee configuration engine that the V1 backend does not yet expose.

Fee accounting boundary PrimePay V1 already calculates PrimePay fee, provider fee, total fee and merchant net amount at the transaction level. A global admin fee configuration editor is not currently exposed by the backend, so this console focuses on truthful accounting visibility rather than fake sliders that merely look financially impressive.
